# Welcome to Temper

Temper is a blazing-fast EVM transaction simulation API that lets you preview transaction outcomes before sending them on-chain. Get detailed traces, gas estimates, state changes, and a visual debugger - all without spending gas.

## Quick Start

Simulate a transaction in seconds:

```bash
curl -X POST https://api.temper.dev/api/v1/simulate \
  -H "Content-Type: application/json" \
  -d '{
    "chainId": 1,
    "from": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "to": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
    "data": "0xa9059cbb000000000000000000000000d8dA6BF26964aF9D7eEd9e03E53415D37aA960450000000000000000000000000000000000000000000000000000000005f5e100",
    "gasLimit": "0x100000",
    "value": "0x0"
  }'
```

Response includes:

```json
{
  "id": "abc123xyz",
  "simulation_url": "https://temper.dev/simulation/abc123xyz",
  "success": true,
  "gas_used": 51234,
  "logs": [...],
  "enhanced_trace": {...}
}
```

## Features

### Transaction Simulation
Simulate any EVM transaction and get detailed results including:
- Success/failure status with revert reasons
- Exact gas usage
- Event logs with decoded parameters
- Full call trace tree
- State changes

### Visual Simulation Viewer
Every simulation gets a shareable URL with:
- Transaction overview
- Call trace visualization
- Decoded function calls and events
- Token transfer tracking
- Gas breakdown

### Step-by-Step Debugger
Debug failed transactions with:
- Source code view with syntax highlighting
- Function-level navigation
- Decoded input parameters
- Call stack visualization
- Contract source from Sourcify/Etherscan

### Bundle Simulation
Simulate multiple transactions in sequence:
- Atomic bundle execution
- Shared state between transactions
- Perfect for MEV and complex DeFi strategies

### Stateful Simulation
Create persistent simulation environments:
- Fork blockchain state
- Execute multiple transactions
- Inspect intermediate states
- Perfect for testing sequences
