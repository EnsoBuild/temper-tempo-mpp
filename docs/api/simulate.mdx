# Simulate Transaction

Simulate a transaction without broadcasting it to the network. Returns execution results, gas usage, logs, and a shareable simulation URL.

## Request

<ParamField body="chainId" type="number" required>
  The chain ID to simulate on (e.g., 1 for Ethereum, 137 for Polygon)
</ParamField>

<ParamField body="from" type="string" required>
  The sender address (0x-prefixed, 40 hex characters)
</ParamField>

<ParamField body="to" type="string" required>
  The target contract address
</ParamField>

<ParamField body="data" type="string">
  The calldata (0x-prefixed hex string). For contract calls, this is the encoded function selector + arguments
</ParamField>

<ParamField body="value" type="string">
  The ETH value to send (hex string, e.g., "0x0" or "0xde0b6b3a7640000" for 1 ETH)
</ParamField>

<ParamField body="gasLimit" type="string" required>
  Maximum gas for the transaction (hex string, e.g., "0x100000")
</ParamField>

<ParamField body="blockNumber" type="number">
  Specific block number to simulate at. Defaults to latest
</ParamField>

<ParamField body="blockTimestamp" type="string">
  Override block timestamp (hex string)
</ParamField>

<ParamField body="stateOverrides" type="object">
  Override account states before simulation. See [State Overrides](#state-overrides)
</ParamField>

<ParamField body="formatTrace" type="boolean">
  If true, returns human-readable formatted trace. Default: false
</ParamField>

<ParamField body="accessList" type="array">
  EIP-2930 access list for gas optimization
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique simulation ID for retrieving results and viewing in UI
</ResponseField>

<ResponseField name="simulation_url" type="string">
  URL to view the simulation in the web interface
</ResponseField>

<ResponseField name="success" type="boolean">
  Whether the transaction succeeded
</ResponseField>

<ResponseField name="gas_used" type="number">
  Actual gas consumed by the transaction
</ResponseField>

<ResponseField name="block_number" type="number">
  Block number the simulation was executed at
</ResponseField>

<ResponseField name="return_data" type="string">
  Return data from the transaction (hex string)
</ResponseField>

<ResponseField name="exit_reason" type="string">
  EVM exit reason (e.g., "Return", "Revert", "OutOfGas")
</ResponseField>

<ResponseField name="logs" type="array">
  Array of event logs emitted during execution
</ResponseField>

<ResponseField name="enhanced_trace" type="object">
  Full call trace tree with nested calls, inputs, outputs
</ResponseField>

## State Overrides

Override account state before simulation. Useful for testing with custom balances or modified contracts.

```json
{
  "stateOverrides": {
    "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045": {
      "balance": "0xde0b6b3a7640000",
      "nonce": 100,
      "code": "0x...",
      "stateDiff": {
        "0x0": "0x1234..."
      }
    }
  }
}
```

### Override Options

| Field | Description |
|-------|-------------|
| `balance` | Set account ETH balance (hex) |
| `nonce` | Set account nonce |
| `code` | Replace contract bytecode |
| `state` | Replace entire storage (clears existing) |
| `stateDiff` | Modify specific storage slots (preserves others) |

## Error Responses

```json
{
  "success": false,
  "exit_reason": "Revert",
  "return_data": "0x08c379a0...",
  "enhanced_trace": {
    "error": "Revert",
    "revert_reason": "Insufficient balance"
  }
}
```

```json
{
  "error": "No RPC URL configured for chain 999999"
}
```
