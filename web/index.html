EVM Transaction Simulator

Simulate Ethereum Transactions

Temper allows you to simulate EVM transactions and inspect their execution traces.

API Endpoints

  • POST /api/v1/simulate - Simulate a single transaction
  • POST /api/v1/simulate-bundle - Simulate multiple transactions
  • GET /api/v1/simulation/{id} - Get stored simulation
  • GET /api/v1/simulation/{id}/trace - Get trace for viewer
